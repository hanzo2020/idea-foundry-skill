# IdeaFoundry Excluded-Paper Ledger

This ledger records papers screened out of the main ML/AI component library by the research-scope gate.

## Entry Format

### PXXX. Paper Title

- **Scope disposition:** OUT -> Domain-specific.
- **Primary domain:** Hardware / chips / architecture / networks / systems / robotics platform / benchmark-only / other.
- **Candidates reviewed:** List the 2-3 decomposed candidates.
- **Exclusion reason:** State which platform-removal, mechanism-survival, transfer, or evidence tests failed.
- **Transferable hook, if any:** Record a weak related idea without promoting it to a main-library component.
- **Repository screen:** Record the repository result independently.
