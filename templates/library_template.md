# IdeaFoundry Library

## 0. Usage Guide

This library stores reusable theory-grounded method components extracted from foundational theory papers and application-oriented method papers.

Use this library by starting from one of three questions:

1. What modeling problem am I facing?
2. What theoretical foundation do I want to explore?
3. What type of model component do I want to design or replace?

Each component is described as an input-mechanism-output unit with applicability conditions and failure boundaries.
