# IdeaFoundry

[English](./README.md) | [中文](./README_zh.md)

A minimal Codex skill for mining theory-grounded research components from PDF papers into one cumulative Markdown library for future idea generation.

## Files

- `SKILL.md`: main skill instruction file.
- `templates/library_template.md`: default cumulative library structure.
- `templates/component_card_template.md`: component card template.

## Suggested installation path

Copy the `idea-foundry` folder to your Codex skills directory, for example:

```text
C:\Users\hanzo\.codex\skills\idea-foundry
```

Then restart Codex.

## Suggested command

```text
Use the IdeaFoundry skill. Read all PDF papers in [folder path], extract theory-grounded method components, and update idea_foundry_library.md. Do not create one file per paper. Deduplicate similar components and update the indexes.
```
